Marginalia

AI academic research assistant · Personal project

Answers questions about an uploaded research paper using only that paper, and cites the page each answer comes from.

How a paper becomes an answer

  1. UploadPDF via JWT-secured API
  2. QueueCelery workers, Redis
  3. ExtractText with PyMuPDF
  4. ChunkPage-tagged passages
  5. Embedsentence-transformers
  6. IndexPer-paper FAISS
  7. AnswerGemini, with page citations

What I built

  • The complete RAG pipeline, from PDF extraction to grounded answers.
  • Page-tagged chunking, so every answer can point back to its source page.
  • A separate FAISS index for each paper, so retrieval stays within one document.

Engineering

  • Long-running PDF processing runs in Celery workers backed by Redis.
  • FastAPI REST APIs secured with JWT, with data in MySQL.
  • React and TypeScript interface, Docker Compose setup, pytest tests.
